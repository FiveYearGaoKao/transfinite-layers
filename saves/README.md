# 基准存档(存档银行)

本目录存放**基准存档**:从空白档跑机器人(`scripts/bot.ts` 的阶段式策略)到各个阶段节点时导出的存档。两个用途:

1. **模拟脚本的统一起点**:长测与对照实验都从同一个基准档出发,结果才可比(见 [测试与平衡.md](../docs/面向开发者/测试与平衡.md) §五);
2. **玩家接续**:存档丢失或不想从头跑时,可以导入与自己进度接近的基准档继续玩。

## 命名

```
TransfiniteLayers-<版本号>-baseline-<序号>-<阶段>.txt
```

| 序号 | 阶段                | 判定条件                    | 说明                                   |
| ---- | ------------------- | --------------------------- | -------------------------------------- |
| 01   | start               | 空白档                      | 与"新游戏"完全一致                     |
| 02   | challenges          | 解锁挑战页(成就 a28 Googol) | 已有若干层级,准备进 C1                 |
| 03   | infinity            | 第 1 次无限重置             | 无限点数与无限升级入口刚打开           |
| 04   | infinity-challenges | 购买无限升级 iu15           | 无限挑战已解锁                         |
| 05   | meta-boost          | 购买无限升级 iu25           | 元维度提升已解锁                       |
| 06   | world-limit         | 0阶窗口填满(层级0~9 都在)   | v0.2.0 的终局:再解锁下一个层级会被拒绝 |

目录里其它 `TransfiniteLayers-*.txt` 是玩家自己导出的存档,不属于基准档。

## 导入

选项 → 设置 → 存档 → "从文件导入",选择本目录里的 txt;导入会覆盖当前槽位,建议先导出自己的存档。
基准档可以跨版本载入(缺失字段按 `initializeSave` 补齐),但版本号比当前 `gameVersion` 老时可能缺新内容。

## 生成与更新

```sh
npm run saveBank                    # 全部阶段(会跑机器人,耗时长)
npm run saveBank -- --minutes=600   # 只跑到指定游戏时间(分钟)
npm run saveBank -- --stages=02,03  # 只导出指定阶段
```

阶段没跑齐时脚本会报出"未到达"的序号:先按 [测试与平衡.md](../docs/面向开发者/测试与平衡.md) §五调整机器人策略或放宽时间,不要手动改档。

## 模拟脚本使用

```sh
node scripts/run-ts.mjs scripts/sim.ts 60 1 60 --bot=phased --save=TransfiniteLayers-v0.2.0-baseline-04-infinity-challenges.txt
```

`--save=` 只写文件名(自动到本目录下找);不填时按"仓库根目录下的玩家存档"处理,`--fresh` 则从空白档开始。
