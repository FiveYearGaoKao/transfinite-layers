# 剧情大纲(参考稿)

> 用途:给策划的参考稿——**世界观事实 + 分镜**。**不进游戏**:`src/data/story.ts` 只保留章节骨架与解锁条件,正文由策划决定是否采用。
> 本文不含成稿正文,只写"每一格必须交代的事实"。写法约束见 §六。
> 依据:机制以代码为准([层级系统.md](./层级系统.md)、[测试与平衡.md](./测试与平衡.md));"该怎么做"的玩家向内容在 [进阶攻略.md](../面向玩家/进阶攻略.md)。

## 一、一句话设定

**塔不需要任何人。是你在给它编号。**

- 塔 = `ω^ω` 个层级的结构,中立的定律:没有意志、没有目的、不欠你任何东西;
- 你做的每一件事只有两种:**按已有规则往上走**,或者**换一套写法**(进位、因子转换);
- 全程没有反派、没有战斗:唯一的阻力是**容量与极限**。

## 二、由设定推出的硬事实(都有机制依据)

| 事实                                         | 机制依据                                                                              |
| -------------------------------------------- | ------------------------------------------------------------------------------------- |
| 往上走没有奖励,只有更多编号                  | 层级就是重置层,没有"通关奖励"这种东西                                                 |
| 每上一层,必须丢掉脚下层的全部内容            | 重置清空下层、删层(`wipeLayerScope`/`wipeLayersWhere`)                                |
| 只有"你学到的"跨过所有重置:知识、成就        | 任何重置都不清成就与知识;无限层、元维度提升次数等只是"当前版本还没有更高一层来重置它" |
| 0 阶窗口只装得下 0~`base-1`(自然数);ω 在其上 | 窗口满 ⇒ 轮转 / 进位 / 拒绝(见层级系统.md §六)                                        |
| ω 的重置会把整条自然数梯子删掉               | ω 的重置作用域是区间 `([0],[1,0])`,层级1~9、层级10… 都在里面                          |
| 有些东西不是塔的一部分,而是别人留下的        | 无限点数/无限升级/无限里程碑不随无限重置清空                                          |

**术语对照(写正文时按这个用词)**

| 机制                        | 设定里的说法                                      |
| --------------------------- | ------------------------------------------------- |
| 层级 / 维度 / 升级 / 可购买 | 塔的层与"你在这层变强的形态"(几句带过,不当实体写) |
| 重置                        | 丢掉脚下这一层                                    |
| 点数 / 能量                 | 这一层的产出                                      |
| 进位 / ω                    | 一个数位用完了:自然数之上是新的一层               |
| 无限层                      | 前任留下的工具(不随重置消失)                      |
| 奇点 / 树                   | 更高一层的视角("每重置一次更难,但解锁更多特权")   |
| 因子转换(序数层)            | 换一套写法:`base` 减 1,你原来的"地址"全部作废     |
| 知识 / 成就                 | 你学到的、你做过的事——唯一跨过所有重置的东西      |

## 三、谁能爬上去:主角的三条特征

1. **会改写法**:进位与因子转换不是塔里的规则,而是换一套规则。自动化只会照抄给定规则,所以它爬到规则允许的地方就停(连贪心机器人都能到第 3 层,这恰恰是证据);
2. **会做没有即时收益的事**:这个游戏的永久强化几乎都来自"反最优"的操作(a24 一秒内再重置、a27 不买维度让能量为 0、a45 只买维度1 硬打到 1e50…);
3. **愿意主动接受更苛刻的条件**:奇点层的设定就是"每重置一次游戏更难,但解锁更多特权"。

⇒ 所以"为什么只有主角"既不是血统问题,也不是"别人进不来"(塔对所有人开放),而是这三条。

## 四、人物与声音

- **不塑造性格、不写对话**。唯一的人声是**前任攀登者的记录**,它的作用是新手指引与攻略;
- 刻画他的办法:看他**留下了什么、卡在哪里**——他留下了无限层(不随重置消失的工具),他的记录在 0 阶窗口填满处断了;
- **反派:不需要**。冲突的唯一形态是"表示能力的上限"(窗口容量、`base` 最低 3、最多 7 次因子转换)。

## 六、写法约束(策划自用)

- 不解释数值与公式;机制名词直接用游戏里的名字;
- 不堆辞藻、不排比,不用"仿佛/宛如/无尽/轮回/宿命/低语"这类词;
- 不写战斗、不写"神"、不写战力:收尾是"你把写法压到了尽头"(`base` 最低 3、最多 7 次因子转换),不是胜利;
- 每段只做一件事:交代事实 / 给一个可操作的动作 / 留一个悬念;
- 可以顺手承载两条新手向提示(与 [进阶攻略.md](../面向玩家/进阶攻略.md) 重合):**先拿 a24 再打层级2**、**进挑战前先攒够资源**。
