# 玩法指南

> 面向玩家。v0.1.0 已实现内容的玩法说明。若与游戏内实际不符,以游戏内为准。

## 一、目标

这是一款增量游戏。你的最终目标是让**层级0点数达到 1.79e308**,并抵达"无限"。
核心循环:生产点数 → 重置晋升 → 解锁更高层级 → 获得能量 → 生产更快 → 循环。

顶部**资源栏**以表格形式显示最高层级、点数、知识、当前挑战与其它层资源,可在 选项→设置→资源栏 自定义显示项。

## 二、层级(Layers)

- 本游戏有 ω^ω 个常规层级,每个层级有若干维度:第1维度生产**点数或能量**,第2维度生产第1维度,以此类推。
- **层级0**特殊:第1维度直接生产点数,且永不重置。
- 重置某个层级会清空它的下层,并根据下层点数给予该层点数(晋升)。
- 层级编号用数组表示,如 `层级1,0`。层级0 → 层级1 → 层级2 …逐个解锁。

## 三、点数与能量

- 层级 k 的**能量**由该层的维度1生产,能量会为 k-1 层的所有维度提供随时间递增加成。
- 能量是后期把点数推向 1e308 的主力乘区。

## 四、升级与可购买

- **升级**(一次性):每个层级可购买,如"点数作用""自协同""额外加速器""自动化""能量保留""升级保留"等。
- **可购买**(可重复):加速器(提升所有生成器速度)、加倍器(提升点数获取)、加速器加成(提升加速器效果,需成就 a22 解锁)。

## 五、成就与知识

- **成就**达成后奖励**知识**;部分成就解锁额外效果。
- **知识**是跨重置货币,用于:
  - 解锁知识升级(时间系统、指令系统、加成等);
  - 兑换离线时间(1知识 = 1分钟)。
- 知识页分"知识升级"与"时间"两个子页。

## 六、指令

解锁知识升级"指令系统"后,在底部工具栏输入框输入指令(以 `/` 开头,使用英文):
- `/checkin` 每日签到,获得 (0~100) + 10×连续签到天数 知识;
- `/help` 列出所有可用指令;
- `/set <键> <值>` 修改设置(如 `/set theme light`);
- `/egg` 彩蛋;
- `/quiz` 答题(需解锁"答题"),答对获得知识(有冷却,答对奖励随难度升级提升)。题目包含游戏机制/梗题题库(机制题随相关机制解锁才出现,防剧透)与随机数学题;数学题分**六个难度等级**(随"博学"升级提高,逐步解锁乘除、取模、乘方、取整、开方等算符,答案可为小数时允许误差)。

## 七、挑战

解锁成就 a28 后开放挑战页。挑战需要在特定条件下重置并达成目标,完成后获得永久奖励。
当前普通挑战:c1 无加速器、c2 无加倍器、c3 能量衰弱、c4 立即折算、c5 维度蒸发。
普通挑战之间互斥(同时只能进行一个),进入新挑战会自动退出当前挑战。

## 八、自动化

- 在层级 L 购买"自动化1/2"后,可自动购买 L-1 层的维度/可购买;购买"自动重置"后可按条件自动重置本层。
- 自动化页可逐层配置购买顺序、消耗比例、购买数量、重置条件。

## 九、时间系统

- **离线时间**:离线时产出(需知识升级链解锁),可兑换/转换为加速时间,或用加速稳定提升全局速度。
- **暂停**:需知识升级"时间暂停";暂停期间时间会储存为离线时间。
- **时间扭曲**:有加速时间时自动开启,每帧消耗 1% 快速推进游戏。

## 十、快捷键

- 数字键 `1~9/0`:切换主标签;
- `←`/`→`:层级页切换所选层级,其余页切换子标签;
- `Shift+1~4`:购买当前层维度1~4;
- `R`:重置当前层(受二次确认设置控制);
- `S`/`L`:弹出存档/读档对话框;
- `A`/`Shift+A`:开关当前层/全部自动化;
- `B`:循环加速。

## 十一、统计

选项→统计 分"加成明细"与"资源明细"两页。
**加成明细**:每维度一棵"产量树"(初始值→维度乘数→维度指数→最终加成,可逐级展开查看每个来源);另有一棵"点数获取"树(`+` 开头,含初始值:层0为维度1产量、层1+为重置收益基础值,以及加倍器/点数作用/深度加成等来源,层0含软上限);下方为全局加成(全局速度、答题冷却)。
**资源明细**:存档/时间、全局统计(新闻/指令/答题/签到)、每层资源(点数/能量/重置时间/次数/最佳点数/累计点数)。

## 十二、无限(建设中)

达到 1.79e308 点数解锁成就 a48 与"无限"标签。无限层为 v0.1.0 的框架终点,后续版本开放。
